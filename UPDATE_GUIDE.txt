WADHWANI REGISTRATION — POLITE ALERT + NAME CHECK V9
===================================================

MAIN CHANGES
1. Call/Remind now uses a soft two-tone flight-attendant-style chime, followed by a slower and softer spoken reminder:
   “Attention user WR-004. This is a reminder to proceed with your registration. Please proceed to the CARES Office for assistance. Thank you.”
   The queue number is spoken slowly for clarity. The alarm continues at a calmer interval until the student responds.

2. Messenger/Facebook browser notice
   - Removed the “Continue Here” button.
   - Students must use Open Chrome or Copy Link.

3. Duplicate full-name prevention before Choose Schedule
   - The backend checks First Name + Middle Name + Last Name before the schedule screen opens.
   - If the same normalized full name already exists under another Student ID, registration is stopped and a CARES assistance message is shown.
   - The same check is repeated inside registerStudent() under the write lock to prevent duplicate submissions/race conditions.
   - Cancelled registrations are ignored by the duplicate-name check.

4. College choices are now exactly:
   - College of Arts and Sciences
   - College of Business and Accountancy
   - College of Education
   - College of Engineering and Technology
   - College of Computing Multimedia Arts and Digital Innovation

5. Course is now a REQUIRED text input rather than a dropdown.

6. MY BATCH LIST shows names as:
   First Name M. Last Name
   Example: Mark Anthony C. Fajela
   The backend now also includes first/middle/last/course fields in the batch member response so the student Ongoing list can show names and course correctly.

REQUIRED DEPLOYMENT
1. Replace Code.gs with this V9 version.
2. Save the Apps Script project.
3. Run setupSystem() once after replacing Code.gs.
4. Deploy a NEW Web App version.
5. Copy the new /exec URL into APPS_SCRIPT_WEB_APP_URL in script.js if the URL changes.
6. Upload index.html, script.js, style.css and _headers together.

IMPORTANT
- Existing registration rows are preserved.
- No new registration sheet columns are required.
- The schema version is bumped to 10 to make sure the updated backend is installed.
